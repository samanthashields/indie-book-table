# Soften and modernize Book Cycles

## Direction
Refresh the full product using the selected **Soft editorial archive** direction, informed by the Tertulia reference. Preserve every current screen, navigation path, label, and publishing workflow; this is a visual adaptation, not a structural rebuild.

- **Typography:** Recoleta for book titles and key headings; Garet for navigation, controls, forms, and body copy. Use close system fallbacks only where licensed webfont files are unavailable.
- **Palette:** `#e6b348` golden amber, `#b4c85b` fresh green, `#67c3c0` soft teal, `#eee5db` warm paper, `#4b779a` muted blue, and `#3a241f` deep brown. Deep brown anchors text; warm paper and near-white carry most surfaces; the brighter colors appear selectively for momentum, state, and phase cues.
- **Shape:** Replace hard rectangular sections with a consistent soft radius system: rounded controls and pills, gently rounded rows and panels, and larger radii only for major grouped areas. Use quiet borders and restrained shadows rather than a wall of floating cards.
- **Motion:** Add subtle 150–220ms fades, color transitions, and small elevation changes that respond to selection or hover; preserve reduced-motion behavior.

## Work
1. **Rebuild the shared visual foundation**
   - Replace the current colors, fonts, radii, borders, and shadows with semantic tokens matching the selected direction.
   - Update shared buttons, inputs, status pills, progress bars, headings, and focus states so all screens inherit the softer treatment consistently.
   - Load Recoleta and Garet from supplied/licensed font files when available; otherwise provide carefully matched fallbacks without blocking the redesign.

2. **Soften the application frame**
   - Restyle the left navigation as a calm rounded rail with a soft selected state and clear author area.
   - Keep the focused dashboard proportions while giving the main workspace more breathing room.
   - Restyle the Book Coach as a quieter rounded companion panel, preserving collapse, mobile access, prompts, and messaging behavior.

3. **Apply the selected direction across the product**
   - **My Books:** rounded priority summary, softer book rows with existing covers and publishing progress, and a clear create action.
   - **Create Book Cycle:** rounded choice sections, conversation turns, answer chips, progress rail, generated preview, and supporting guidance.
   - **Book Overview:** soften phase groups and milestone rows while retaining numbered markers only on the phase timeline.
   - **Milestone detail:** clarify author/collaborator areas, requirement action, status, attachments, notes, and approval controls with rounded grouped sections.
   - **Book Details and Reflection:** modernize form fields, selectors, prompt groups, and save actions while preserving all conditional behavior.
   - **Templates:** retain the genre-specific structure and Children’s Picture Book option, presented with the same soft editorial hierarchy.

4. **Responsive and visual verification**
   - Check the main dashboard, creation flow, book overview, milestone detail, details form, reflection, and templates on desktop and mobile.
   - Verify text wrapping, navigation behavior, Book Coach collapse/open states, form focus, color contrast, and reduced motion.
